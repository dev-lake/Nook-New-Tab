## English (en-US)

### Name

Nook — New Tab

### Short description

A calm new tab with your bookmark tree and browser tools.

### Detailed description

Nook turns every new tab into a calm, focused home for your browser.

Your real bookmark tree appears directly on the left, including nested folders that can be expanded without leaving the page. On the right, Nook provides a clean search field, editable pinned shortcuts, optional live data within matching GitHub repository and profile shortcuts, and compact links to essential browser pages.

Highlights:

- View and open your existing browser bookmarks from the new tab page.
- Pin a bookmark to the shortcut area directly from the bookmark sidebar.
- Click the Nook browser-toolbar icon to review or edit the current HTTP/HTTPS page's name and URL in a compact confirmation window before adding it to Pinned. Matching GitHub repository and profile URLs offer the same optional live-data enhancement available in the main shortcut editor.
- Expand bookmark folders of any depth, choose a specific folder as the sidebar root, and keep that state on this device.
- Create, edit, delete, and drag to reorder pinned shortcuts without an app-defined item limit.
- Organize multiple shortcuts inside a compact, folder-like group card and drag the whole group to reorder it.
- When adding or editing a GitHub public-repository URL, optionally enable repository counters inside that same shortcut card. GitHub home-page and Profile shortcuts can similarly show a selected public account's username, followers, and public repositories. Enhanced shortcuts can be grouped and reordered like every other shortcut.
- Search a localized catalog of popular global and Chinese websites when adding a shortcut.
- Display website icons using the browser favicon cache and locally bundled brand icons, with a direct website fallback.
- Search with Google, Bing, or DuckDuckGo, or type a complete URL to navigate directly.
- Choose a bundled background or use a custom image stored only on this device.
- Choose System, Light, or Dark appearance.
- Use the interface in English, Simplified Chinese, or Japanese.
- Open useful browser management pages without requesting history, downloads, tabs, or extension-management access.
- Use or dismiss the subtle bottom-right rating link. Dismissing snoozes it for three weeks; opening the rating destination treats the prompt as completed so it does not keep interrupting the user.

Privacy by design:

Nook has no developer-operated backend, analytics, advertising, or account system. It reads bookmarks only to display them in the new tab page. When the toolbar icon is clicked, temporary `activeTab` access reads only that page's title and URL to create the requested shortcut. Preferences, pinned shortcuts, and component configurations use the browser's built-in storage and sync facilities. Public repository or profile data is requested directly from GitHub only after the user enables the corresponding shortcut feature, and is cached locally. Bookmark contents are not copied into extension storage or sent to the developer.

Installing Nook replaces the browser's default New Tab page. You can disable or remove the extension at any time from your browser's extension management page.

## 简体中文 (zh-CN)

### 名称

Nook 新标签页

### 短描述

在安静的新标签页中查看书签树和浏览器工具。

### 详细描述

Nook 将每一个新标签页变成安静、专注的浏览器起点。

真实的浏览器书签树会直接显示在页面左侧，包括任意层级的书签文件夹；用户无需离开页面即可展开目录并点击跳转。右侧提供简洁的搜索框、可编辑的固定快捷项、GitHub 仓库与账号快捷项实时数据和常用浏览器入口。

主要功能：

- 在新标签页中直接查看并打开当前浏览器的真实书签。
- 直接从左侧书签栏将网页固定到快捷项区域。
- 点击浏览器工具栏中的 Nook 图标，在紧凑的确认窗口中查看或修改当前 HTTP/HTTPS 页面的名称和网址，再添加到固定快捷项；匹配 GitHub 仓库或账号时，可在同一窗口选择开启实时数据增强。
- 展开任意深度的书签文件夹，选择特定文件夹作为侧边栏根目录，并在当前设备记住该状态。
- 新增、编辑、删除固定快捷项，并通过拖动调整顺序，不设应用内数量上限。
- 将多个快捷项收纳在一个类似文件夹的紧凑分组卡片中，并可拖动整个分组调整顺序。
- 添加或编辑 GitHub 公开仓库网址时，可选择在同一个卡片中显示 Stars、Forks 和待处理问题；GitHub 主页和 Profile 快捷项还可显示指定公开账号的用户名、关注者和公开仓库数量。增强快捷项可像普通快捷项一样分组、编辑、删除和排序。
- 添加快捷项时，可搜索根据界面语言排序的国内外常用网站。
- 使用浏览器本地图标缓存和扩展内置品牌图标显示真实网站图标，必要时尝试读取网站自身图标。
- 支持 Google、Bing、DuckDuckGo 搜索，也可以输入完整网址直接访问。
- 选择内置背景，或使用仅保存在当前设备的自定义图片。
- 支持跟随系统、浅色和深色外观。
- 支持英文、简体中文和日文。
- 无需历史记录、下载、标签页或扩展管理权限，即可打开常用浏览器管理页面。
- 使用或关闭右下角的轻量好评入口；关闭后会暂停三周，打开评价页面后则视为已处理，不再反复打扰。

隐私设计：

Nook 不使用开发者后端、分析埋点、广告或独立账号系统。书签仅用于在新标签页中显示，不会复制到扩展存储，也不会发送给开发者。仅在点击工具栏图标时，临时的 `activeTab` 权限会读取该页面的标题和网址来创建快捷项。偏好设置、固定快捷项和组件配置使用浏览器提供的存储与账号同步能力。用户主动启用 GitHub 仓库或账号快捷项功能后，对应公开数据会直接从 GitHub 获取并缓存在本机。

安装 Nook 后，浏览器默认的新标签页会被替换。用户可以随时在扩展管理页面停用或卸载 Nook。

## 日本語 (ja)

### 名前

Nook — 新しいタブ

### 短い説明

ブックマークツリーとブラウザツールを静かな新しいタブに。

### 詳細説明

Nook は、新しいタブを落ち着いて集中できるブラウザのホーム画面に変えます。

ブラウザに保存されている実際のブックマークツリーを左側に表示し、階層化されたフォルダーをページ内で展開できます。右側には検索、編集可能なピン留めショートカット、GitHub リポジトリとアカウントのショートカット内ライブデータ、主要なブラウザ管理ページへの入口があります。

主な機能：

- 新しいタブから既存のブックマークを表示して開く。
- ブックマークサイドバーからページを直接ピン留め。
- ブラウザツールバーの Nook アイコンをクリックし、コンパクトな確認画面で現在の HTTP/HTTPS ページの名前と URL を確認または編集してからピン留めに追加。GitHub リポジトリまたは Profile の URL では、同じ画面でライブデータ拡張を選択できます。
- 任意の深さのブックマークフォルダーを展開し、特定のフォルダーをサイドバーのルートに選択。
- アプリ固有の件数上限なしでショートカットを追加、編集、削除し、ドラッグで並べ替え。
- 複数のショートカットをフォルダーのようなコンパクトなグループカードに整理し、グループ全体をドラッグして並べ替え。
- GitHub 公開リポジトリの URL を追加または編集する時、同じカード内に Stars、Forks、未解決 Issue を表示可能。GitHub ホームページと Profile のショートカットでは、指定した公開アカウントのユーザー名、フォロワー、公開リポジトリ数も表示できます。通常のショートカットと同様にグループ化、編集、削除、並べ替えができます。
- 言語に合わせて並ぶ中国・海外の人気サイトを検索してショートカットに追加。
- ブラウザの favicon キャッシュとローカルに同梱したブランドアイコンを利用し、必要な場合はサイト自身のアイコンへフォールバック。
- Google、Bing、DuckDuckGo による検索と、完全な URL の直接入力。
- 同梱背景またはこの端末にのみ保存されるカスタム画像を選択。
- システム、ライト、ダークの外観設定。
- 英語、簡体字中国語、日本語に対応。
- 履歴、ダウンロード、タブ、拡張機能管理の権限を要求せず、主要なブラウザ管理ページを開く。
- 右下の控えめな評価リンクは閉じることもでき、閉じた場合は3週間後に再表示されます。評価ページを開いた後は完了として扱い、繰り返し表示しません。

プライバシーを重視：

Nook には開発者運営のバックエンド、解析、広告、独自アカウントがありません。ブックマークは新しいタブに表示するためだけに読み取られ、開発者へ送信されません。ツールバーアイコンをクリックした時だけ、一時的な `activeTab` アクセスでそのページのタイトルと URL を読み取り、ショートカットを作成します。設定、ピン留めショートカット、コンポーネント設定はブラウザ標準のストレージと同期機能を使用します。GitHub のリポジトリまたはアカウント機能をユーザーが有効にした場合のみ、対応する公開データを GitHub から直接取得し、端末内にキャッシュします。

Nook をインストールすると、既定の新しいタブページが置き換えられます。ブラウザの拡張機能管理ページからいつでも無効化または削除できます。
