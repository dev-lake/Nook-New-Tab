# 商店图片素材计划

## 必备与建议尺寸

### Chrome Web Store

- 商店图标：128 × 128 PNG
- 截图：至少 1 张，建议 3–5 张，1280 × 800
- 小型宣传图：440 × 280 PNG/JPEG
- 大型宣传图：1400 × 560 PNG/JPEG，可选
- YouTube 演示视频：可选

### Microsoft Edge Add-ons

- 扩展 Logo：正方形，建议 300 × 300，最低 128 × 128
- 小型宣传图：440 × 280，可选
- 大型宣传图：1400 × 560 PNG，可选
- 截图：最多 6 张，640 × 480 或 1280 × 800
- YouTube 演示视频：可选，视频应关闭广告

## 截图方案

所有截图应使用真实运行界面，但必须使用专门准备的非敏感书签数据，不得出现私人邮箱、内部域名、账号、客户名称或个人信息。

1. **Your bookmarks, at a glance**  
   浅色模式，展示左侧两层书签目录和右侧 Pinned 主内容。

2. **A focused place for everyday links**  
   展示真实网站图标、添加按钮和拖放排序中的插入指示线。

3. **Browser tools, always within reach**  
   展示底部 Browser utilities，并让一个图标处于悬停状态以显示名称。

4. **Light, dark, or system**  
   深色模式截图，打开独立的 Appearance 面板。

5. **English, 简体中文, 日本語**  
   可选三联图或分别本地化截图，展示语言面板与中文/日文界面。

6. **GitHub insights inside shortcuts**
   展示 GitHub 仓库或账号的普通快捷项编辑窗口，以及启用后同一卡片中的仓库计数或账号摘要。使用公开演示仓库和公开账号，不显示私人内容。

## 视觉要求

- 不添加与实际功能不符的界面或徽章。
- 不使用 Chrome、Edge、Google、Microsoft 等商标暗示官方关系。
- 不展示评分、下载量、奖项或“最佳”等无法验证的宣传语。
- 保留足够边距，避免商店裁切标题和主要界面。
- 截图应清晰呈现扩展本身，不用浏览器窗口装饰占据大部分画面。
